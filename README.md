# CyberConvert 🚀

A modern, privacy-focused 3D model converter with built-in preview. Convert between 20+ 3D formats locally.

## ✨ Features

- **🔒 100% Private** - All processing happens locally on your machine
- **⚡ Fast** - Direct conversion without internet latency
- **👁️ Built-in 3D Viewer** - Preview models with Three.js
- **📱 Responsive** - Works on desktop, tablet, and mobile
- **🌐 Offline** - Works without internet after loading

## 🎯 Supported Formats

- STL, OBJ, PLY, OFF, 3MF
- glTF, GLB, FBX, DAE, 3DS

## 🚀 Quick Start

```bash
pip install -r requirements.txt
python main.py
```

Then open `http://localhost:5000` in your browser.

## 🧪 Testing

```bash
python -m pytest tests/
```
